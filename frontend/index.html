About this data

Zones are model predictions trained on synthetic historical data standing in for real IMD / CWC / NCS / DGRE / Forest Survey feeds — see disaster_ml_pipeline.py for the real data source mapping. When the backend's live feed has a fresh signal for the current state+hazard (scraped from official bulletins via Firecrawl), the current year and the 6-month forecast are nudged to reflect it — look for the LIVE badge. The forecast view is a documented seasonal heuristic on top of the trained model, not a separately-trained monthly model — see ml/forecast.py.
